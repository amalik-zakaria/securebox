# SecureBox

Projet Linux de surveillance sécurisée d’un répertoire.

---

## Fonctionnalités

- surveillance temps réel avec inotify
- détection CREATE / DELETE / MODIFY
- surveillance récursive des sous-dossiers
- logs automatiques
- alertes sécurité
- statistiques
- architecture multi-threads
- gestion signaux Linux

---

## Technologies utilisées

- langage C
- pthreads
- inotify
- signaux Linux
- Makefile
- appels système POSIX
